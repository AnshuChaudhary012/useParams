# Fieldnotes

A responsive React app built with Vite, Tailwind CSS, and React Router.

## Getting started

```sh
npm install
npm run dev
```

## Routes

- `/` — featured stories
- `/about` — about the project
- Any other path — not-found page

## Project structure

- `src/components/` — shared layout and story card components
- `src/pages/` — route pages
- `src/utility/helper.js` — story card content

Run `npm run build` to create a production build or `npm run lint` to check the source.
